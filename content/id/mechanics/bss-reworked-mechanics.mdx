## Rincian Formula Pertempuran: Cara Penskalaan Pengali Serangan Lebah

Pertempuran lebah tidak lagi hanya tentang menaikkan level Vicious Bee Anda; ini bergantung pada perhitungan berlapis yang tepat. **BSS reworked mechanics** yang mengatur serangan lebah menghitung penambahan dasar (flat) terlebih dahulu sebelum menerapkan pengali persentase. 

```
Total Serangan = (Serangan Dasar Lebah + Bonus Flat Tambahan) × (1 + Pengali Serangan Lebah)
```

Setiap lebah memiliki nilai serangan awal bawaan yang berkisar antara 0 (Baby Bee) dan 10 (Lion Bee). Meskipun Baby Bee dapat menerima buff serangan, lebah ini tetap tidak dapat menyerang musuh.

```

|                        ALUR PERHITUNGAN SERANGAN LEBAH                            |
|                                                                                   |
|  [Serangan Dasar (0-10)] + [Bonus Flat: Guard/Belt/Amulet/Rage Token]             |
|                                         │                                         |
|                                         ▼                                         |
|                           [Total Serangan Perantara]                              |
|                                         │                                         |
|                                         ▼                                         |
|     × [Pengali Persentase: Buff Gifted/Stinger/Nectar/Bonus Sticker]              |
|                                         │                                         |
|                                         ▼                                         |
|       [Hit Dasar Final] ───► Menerapkan [Critical Power] / [Super-Crit Mult]      |
+-----------------------------------------------------------------------------------+
```

## Mekanik Balon dan Siklus Konversi Hive

Balon merupakan salah satu sistem pengumpulan dan konversi paling penting di Bee Swarm Simulator. Balon melayang di atas ladang, menyerap serbuk sari (pollen) yang dikumpulkan dalam radius 5 petak sebelum membawanya langsung ke hive Anda.

```
+-----------------------------------------------------------------------------------+
|                           SIKLUS BALON LADANG KE HIVE                             |

|  [Pengumpulan Ladang] ──► [Balon Ladang Menyerap Pollen (Radius 5 petak)]         |

|                                         ▼                                         |
|                           [Buff Balloon Aura: Hingga x10]                         |
|                             (+20% Honey Dari Token)                               |
|                                         │                                         |
|                                         ▼                                         |
|                         [Balon Kembali ke Pangkalan Hive]                         |
|                                         │                                         |
|                                         ▼                                         |
|                          [Membentuk "Hive Balloon" Utama]                         |
|                                         │                                         |
|                                         ▼                                         |

|                   (+300% Kapasitas / +150% Honey di Hive)                         |
+-----------------------------------------------------------------------------------+
```

### Penyusutan Hive Balloon dan Balloon Blessing

Ketika balon ladang kembali, mereka bergabung menjadi Hive Balloon pusat yang tergantung di atas pangkalan Anda. Mengonversi pollen ini memberi Anda buff **Balloon Blessing**:

* **Penskalaan Maksimum:** Mengumpulkan hingga 10 Triliun pollen yang tersimpan akan mencapai batas maksimum **x100 Balloon Blessing**, memberikan **x4 Kapasitas** dan **x2.5 Madu di Hive**.
* **Mekanik Penyusutan (Depletion):** Pollen di dalam Hive Balloon terus menurun seiring waktu. Jika balon Anda melebihi 100x kapasitas ransel, isi balon akan menyusut hingga 99,99% dalam kurun waktu 10 menit. Balon dengan kapasitas sedang menyusut pada tingkat stabil sekitar 20% per jam.
* **Prioritas Konversi:** Lebah akan mengosongkan seluruh isi ransel Anda terlebih dahulu sebelum mulai mengonversi Hive Balloon.

## Membangun Hive Strategis dengan BSS Reworked Mechanics

Untuk memaksimalkan sistem yang diperbarui di Bee Swarm Simulator, koordinasikan perlengkapan, sticker, dan tipe lebah Anda di sekitar siklus pengali yang padu daripada menumpuk stat secara acak.

```
+-----------------------------------------------------------------------------------+
|                            ALUR PROGRES OPTIMAL                                   |
+-----------------------------------------------------------------------------------+
|  1. DAMAGE DASAR: Dapatkan Crimson/Cobalt Guard & kumpulkan item flat +Serangan   |
|  2. PENGALI: Jadikan gifted lebah kunci (Rage, Brave) & pasang Sticker Serangan   |
|  3. KONVERSI: Rotasikan balon ladang untuk menjaga buff Balloon Aura 10x aktif    |
|  4. PENYIMPANAN: Konversi Hive Balloon berkala guna menjaga 100x Balloon Blessing |
|  5. PENCAPAIAN: Kejar Badge Goo & Hotshot Ladang untuk membuka zona akhir         |
+-----------------------------------------------------------------------------------+
```

1. **Prioritaskan Penambahan Flat di Awal:** Karena pengali melipatgandakan serangan dasar akhir Anda, item yang memberikan flat +Attack (seperti Crimson/Cobalt Guards atau Gifted Brave Bee) memberikan nilai yang jauh lebih besar di awal daripada buff persentase murni.
2. **Pertahankan Balloon Aura:** Menurut laporan komunitas dan pengalaman pemain veteran, mempertahankan buff Balloon Aura 10x selama masa boosting memberikan peningkatan madu substansial sebesar +20% dari pengumpulan token.
3. **Pantau Penyusutan Hive Balloon:** Hindari mengisi Hive Balloon melebihi apa yang dapat dikonversi oleh hive Anda dalam waktu satu jam. Mengonversi sebelum memulai grinding ladang yang intens akan menjaga Balloon Blessing Anda tetap aktif di tingkat maksimum.

## Pertanyaan yang Sering Diajukan (FAQ)

### Apa saja BSS reworked mechanics terpenting yang harus dipelajari terlebih dahulu?
**BSS reworked mechanics** yang paling penting untuk dipahami adalah kalkulasi pertempuran (penambahan flat diterapkan sebelum pengali) dan siklus konversi Balloon Blessing. Berfokus pada kedua aspek ini memastikan pembersihan mob yang cepat dan memaksimalkan konversi madu Anda selama boost ladang besar.

### Apakah bonus stat badge bertumpuk (stack) saat mencapai peringkat yang lebih tinggi?
Tidak. Saat Anda meningkatkan badge dari Cadet ke Hotshot, Ace, Master, atau Grandmaster, bonus stat yang baru akan menimpa bonus dari peringkat sebelumnya, bukan menambahkannya.

### Bagaimana cara kerja sistem penyusutan (decay) Balloon Blessing?
Hive Balloon perlahan-lahan menyusut seiring waktu untuk mencegah penyimpanan pollen tanpa batas. Pengurangan dasar dimulai sekitar 20% per jam untuk balon berukuran wajar, tetapi balon yang menampung lebih dari 100x kapasitas ransel maksimal Anda akan menyusut dengan cepat hingga 99,99% dalam kurun waktu 10 menit.

### Bisakah Baby Bee menghasilkan damage serangan jika ditingkatkan dengan perlengkapan flat attack?
Tidak. Meskipun perlengkapan flat attack dan sticker secara teknis meningkatkan statistik serangan Baby Bee di atas kertas, Baby Bee memiliki batasan serangan bawaan dan tidak akan mengeluarkan stinger atau menargetkan mob dalam pertempuran.
